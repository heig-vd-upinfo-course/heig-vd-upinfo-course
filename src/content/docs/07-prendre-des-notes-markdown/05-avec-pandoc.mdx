Pandoc est un outil en ligne de commande qui convertit des documents d'un format
à un autre. Il supporte une très grande variété de formats d'entrée et de
sortie, et est particulièrement utile pour transformer des notes Markdown en
documents professionnels.

Pandoc peut être utilisé pour convertir des fichiers Markdown en PDF, Word,
HTML, LaTeX, et bien d'autres formats. Il est très apprécié pour sa flexibilité
et sa capacité à produire des documents de haute qualité à partir de simples
fichiers texte.

## Conversions courantes

```bash title="Terminal Bash/Zsh"
# Markdown vers PDF
pandoc notes.md -o notes.pdf

# Markdown vers Word
pandoc notes.md -o notes.docx

# Markdown vers HTML
pandoc notes.md -o notes.html
```

## Support LaTeX

[LaTeX](https://www.latex-project.org/) est un système de composition de
documents très utilisé dans le milieu académique. Pandoc peut générer des
documents LaTeX à partir de Markdown, ce qui permet d'obtenir des PDF de qualité
professionnelle.

De plus, Markdown supporte également l'inclusion de certains aspects de LaTeX,
notamment les formules mathématiques, ce qui est particulièrement utile pour les
documents scientifiques.

## En-tête YAML (frontmatter)

Pandoc supporte un en-tête YAML en début de fichier pour définir les métadonnées
du document et les options de mise en page. Voici un exemple d'en-tête YAML pour
un document Markdown destiné à être converti en PDF avec Pandoc et LaTeX :

```markdown
---
title: "Mon rapport"
author: "Alice Dupont"
date: 20.09.2026
lang: "fr"
geometry: "top=2cm, bottom=2cm, left=2cm, right=2cm"
fontsize: "11pt"
papersize: "a4"
header-includes: |
  \usepackage{fancyhdr}
  \pagestyle{fancy}
  \fancyhead[L]{Entête en haut à gauche}
  \fancyhead[R]{Entête en haut à droite}
  \fancyfoot[LO,LE]{Pied de page en bas à gauche}
  \fancyfoot[CO,CE]{\thepage}
  \fancyfoot[RO,RE]{Pied de page en bas à droite}
  \renewcommand{\footrulewidth}{0.4pt}
---

## Un premier titre de niveau 2

En effet, comme le titre du document est défini dans l'en-tête YAML, il n'est
pas nécessaire de le répéter dans le corps du document. Vous pouvez donc
commencer directement avec le second titre.
```

## Résumé

Pandoc est un outil utile pour quiconque rédige en Markdown et a besoin de
produire des documents dans d'autres formats. Sa maîtrise vous permet de
travailler dans un format simple (Markdown) tout en produisant des documents
d'aspect professionnel.

### Exercice pratique - Télécharger et installer Pandoc (optionnel)

Utilisez les instructions ci-dessous pour installer l'application sur votre
système d'exploitation. Vous pouvez choisir d'utiliser un gestionnaire de
paquets (recommandé) ou d'installer l'application manuellement.

<Tabs syncKey="package-manager">
<TabItem label="WinGet (Windows)" icon="seti:windows">

**N'installez pas Pandoc directement sur Windows.**

Installez-le dans votre distribution WSL (Ubuntu) en suivant les instructions de
l'onglet "apt (Linux)".

</TabItem>
<TabItem label="Homebrew (macOS)" icon="apple">

Pandoc est disponible sur [brew.sh](https://formulae.brew.sh/formula/pandoc) :

```bash title="Shell Bash/Zsh"
brew install pandoc homebrew/cask/basictex
```

</TabItem>
<TabItem label="apt (Linux)" icon="linux">


</TabItem>

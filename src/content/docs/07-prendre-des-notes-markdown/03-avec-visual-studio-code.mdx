Visual Studio Code prend en charge Markdown nativement et constitue un excellent
environnement pour rédiger des notes. Il n'est pas nécessaire d'installer quoi
que ce soit pour commencer.

Pour plus d'informations sur Visual Studio Code, consultez le contenu
[Visual Studio Code](/heig-vd-upinfo-course/05-configurer-son-systeme-dexploitation-et-ses-applications/17-visual-studio-code/).

## Prévisualisation Markdown intégrée

Visual Studio Code propose une prévisualisation Markdown en temps réel. Pour
l'ouvrir :

- Raccourci : `Ctrl+Shift+V` (Windows/Linux) ou `⌘+Shift+V` (macOS).
- Ou cliquez sur l'icône de prévisualisation en haut à droite de l'éditeur
  (icône avec une loupe).

Vous pouvez ouvrir le fichier source et la prévisualisation côte à côte avec
`Ctrl+K V` (ou `⌘+K V`).

## Extensions utiles

Quelques extensions améliorent l'expérience Markdown dans Visual Studio Code :

- [**Markdown All in One**](https://marketplace.visualstudio.com/items?itemName=yzhang.markdown-all-in-one)
  : raccourcis clavier, table des matières automatique, prévisualisation
  améliorée.
- [**Markdown PDF**](https://marketplace.visualstudio.com/items?itemName=yzane.markdown-pdf)
  : : exporte vos notes en PDF.
- [**Markdown Lint**](https://marketplace.visualstudio.com/items?itemName=DavidAnson.vscode-markdownlint)
  : vérification du style et de la cohérence de la syntaxe Markdown.
- [**vscode-pdf**](https://marketplace.visualstudio.com/items?itemName=tomoki1207.pdf)
  : permet de visualiser les fichiers PDF directement dans Visual Studio Code.

Installez ces extensions et vous pouvez les utiliser.

Par exemple, pour générer une table des matières dans votre note, utilisez la
commande `Markdown All in One: Create Table of Contents` dans la palette de
commandes (`Ctrl+Shift+P` ou `⌘+Shift+P`).

Pour exporter vos notes en PDF, utilisez la commande
`Markdown PDF: Export (pdf)`.

## Organiser ses notes

Avec Visual Studio Code, les notes Markdown peuvent être organisées dans un
dossier de votre choix. Une arborescence claire facilite la navigation (voir
contenus
[Stockage](/heig-vd-upinfo-course/03-composants-materiels-et-logiciels-dun-ordinateur/04-stockage/)
et
[Gestionnaire de fichiers](/heig-vd-upinfo-course/05-configurer-son-systeme-dexploitation-et-ses-applications/03-gestionnaire-de-fichiers/))
:

```text
notes/
├── cours/
│   ├── algorithmique.md
│   └── reseaux.md
├── projets/
│   └── projet-a.md
└── references.md
```

La recherche globale (`Ctrl+Shift+F` ou `⌘+Shift+F`) permet de retrouver
rapidement une note par son contenu.

## Synchronisation avec Git

Un dossier de notes Markdown peut être versionné avec Git et synchronisé sur
GitHub ou GitLab. Cela offre un historique des modifications, une sauvegarde
automatique et la possibilité de travailler sur plusieurs appareils (voir
contenu
[Git et GitHub](/heig-vd-upinfo-course/05-configurer-son-systeme-dexploitation-et-ses-applications/19-git-et-github/)).

## Résumé

Visual Studio Code est un environnement polyvalent pour rédiger en Markdown :
prévisualisation intégrée, extensions disponibles et intégration Git native.
C'est un excellent choix si vous souhaitez garder un seul outil pour le code et
les notes.

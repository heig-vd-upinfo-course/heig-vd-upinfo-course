Chaque système d'exploitation propose des outils natifs pour sauvegarder ses
données. Il existe également des solutions tierces offrant plus de flexibilité
ou de fonctionnalités.

## Outils natifs

<Tabs syncKey="operating-system">
<TabItem label="Windows" icon="seti:windows">

### Windows : Historique des fichiers

**L'Historique des fichiers** (File History) est l'outil de sauvegarde intégré à
Windows. Il sauvegarde automatiquement les versions de vos fichiers sur un
disque externe ou un partage réseau.

Activation : Paramètres > Système > Stockage > Options de sauvegarde.

Il faut connecter un disque externe et sélectionner les dossiers à surveiller.
Windows créera automatiquement des copies à intervalles réguliers.

</TabItem>
<TabItem label="macOS" icon="apple">

### macOS : Time Machine

**Time Machine** est l'outil de sauvegarde natif de macOS. Il sauvegarde
automatiquement et incrémentalement l'intégralité de votre Mac sur un disque
externe.

Activation : Réglages système > Général > Time Machine > Sélectionner le disque
de sauvegarde.

Time Machine conserve :

- Les sauvegardes horaires des 24 dernières heures.
- Les sauvegardes quotidiennes du dernier mois.
- Les sauvegardes hebdomadaires pour toutes les périodes plus anciennes.

</TabItem>
<TabItem label="Linux" icon="linux">

### Linux : outils courants

Sur Linux, plusieurs outils permettent de sauvegarder ses données :

- [**rsync**](https://linux.die.net/man/1/rsync) : outil en ligne de commande
  très puissant pour synchroniser des dossiers locaux ou distants (via SSH).
- [**restic**](https://restic.net/) : outil de sauvegarde rapide, sécurisé et
  efficace, avec support du chiffrement et de la déduplication.

</TabItem>
</Tabs>

## Limites des outils natifs

Les outils natifs sont pratiques et faciles à configurer, mais ils présentent
certaines limites :

- Ils sont limités à un écosystème spécifique (Windows, macOS, Linux) et ne sont
  pas toujours compatibles entre eux.
- Ils ne permettent pas toujours de sauvegarder sur des services cloud tiers
  (Google Drive, Dropbox, etc.).
- Ils peuvent manquer de fonctionnalités avancées comme la planification
  flexible, la compression, le chiffrement, ou la gestion des versions.
- Ils sont souvent limités à un seul type de support (disque externe, réseau
  local, etc.) et ne permettent pas de combiner plusieurs destinations.

Si vous pensez que ces limitations sont un problème pour votre usage, vous
pouvez envisager d'utiliser des solutions tierces.

Si, au contraire, vous n'utilisez qu'un seul système d'exploitation et que vous
n'avez pas besoin de fonctionnalités avancées, les outils natifs sont suffisants
pour une utilisation courante.

## Alternatives tierces

Pour une sauvegarde plus flexible et multi-plateforme, il existe des solutions
tierces :

- [**Duplicati**](https://www.duplicati.com/) : solution open source avec
  interface graphique, supporte de nombreuses destinations (local, FTP, S3,
  Backblaze B2, OneDrive, etc.) avec chiffrement.
- [**Kopia**](https://kopia.io/) : outil de sauvegarde et synchronisation avec
  interface graphique, supporte de nombreuses destinations (local, FTP, S3,
  Backblaze B2, OneDrive, etc.) avec chiffrement.

## Résumé

Time Machine (macOS) et l'Historique des fichiers (Windows) sont des outils
natifs faciles à configurer et suffisants pour une utilisation courante. Elles
présentent cependant certaines limites, notamment en termes de compatibilité et
de fonctionnalités avancées. Pour une solution plus flexible et
multi-plateforme, des alternatives tierces comme Duplicati ou Kopia peuvent être
envisagées.

### Exercice pratique - Télécharger et installer Duplicati

Afin de vous proposer un outil de sauvegarde multi-plateforme, nous vous
recommandons d'installer Duplicati. Vous êtes libre d'utiliser un autre outil de
sauvegarde si vous le souhaitez, mais nous ne pourrons pas vous aider à
l'installer.

Utilisez les instructions ci-dessous pour installer l'application sur votre
système d'exploitation. Vous pouvez choisir d'utiliser un gestionnaire de
paquets (recommandé) ou d'installer l'application manuellement.

<Tabs syncKey="package-manager">
<TabItem label="WinGet (Windows)" icon="seti:windows">

    Duplicati est disponible sur [winget.run](https://winget.run/pkg/Duplicati/Duplicati) :

    ```powershell title="Shell PowerShell"
    winget install -e --id Duplicati.Duplicati
    ```

</TabItem>
<TabItem label="Homebrew (macOS)" icon="apple">

    Duplicati est disponible sur [brew.sh](https://formulae.brew.sh/cask/duplicati) :

    ```bash title="Shell Bash/Zsh"
    # Installe l'application
    brew install --cask duplicati
    ```

</TabItem>
<TabItem label="apt (Linux)" icon="linux">

    Les instructions suivantes sont adaptées pour des distributions basées sur Ubuntu/Debian.

    Pour une autre distribution (Fedora, Arch, OpenSUSE, etc.), merci de vous référer à votre gestionnaire de paquets pour installer cette application.

    ```bash title="Shell Bash/Zsh"
    # Installe l'application
    sudo apt install duplicati
    ```

</TabItem>
<TabItem label="Installation manuelle" icon="setting">
      <Steps>

        1. Rendez-vous sur le site officiel de Duplicati : [duplicati.com](https://www.duplicati.com).

        2. Installez Duplicati manuellement selon votre système.

      </Steps>

</TabItem>
</Tabs>

Ouvrez Duplicati et vérifiez que l'application fonctionne correctement.

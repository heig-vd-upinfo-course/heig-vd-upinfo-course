Naviguer dans l'arborescence de fichiers est la première compétence à acquérir
pour travailler efficacement avec le terminal. Toutes les autres commandes
s'appuient sur elle.

## Chemins absolus et relatifs

Comme vu dans le contenu
[Gestionnaire de fichiers](/heig-vd-upinfo-course/05-configurer-son-systeme-dexploitation-et-ses-applications/03-gestionnaire-de-fichiers/),
un **chemin absolu** commence toujours depuis la racine (`/` sur macOS/Linux,
`C:\` sur Windows) et désigne un emplacement fixe.

Un **chemin relatif** est exprimé par rapport au répertoire courant. Les
raccourcis utiles sont :

- `.` : le répertoire courant.
- `..` : le répertoire parent.
- `~` : le dossier personnel de l'utilisateur·trice.
- `-` : le répertoire précédent.

## Commandes de navigation essentielles

Afin de naviguer dans l'arborescence de fichiers, il est important de connaître
certaines commandes de base.

### `pwd` - afficher le répertoire courant

```bash title="Terminal Bash/Zsh"
# Affiche le répertoire courant
pwd
```

`pwd` (Print Working Directory) affiche le chemin absolu du dossier dans lequel
vous vous trouvez actuellement.

### `ls` - lister le contenu d'un dossier

```bash title="Terminal Bash/Zsh"
# Liste les fichiers et dossiers du répertoire courant
ls

# Liste les fichiers et dossiers du répertoire courant avec des détails
ls -l

# Liste les fichiers et dossiers du répertoire courant, y compris les fichiers cachés
ls -a

# Liste le contenu d'un dossier spécifique
ls /home/alice/Documents
```

### `cd` - changer de répertoire

```bash title="Terminal Bash/Zsh"
# Aller dans le dossier Documents (relatif)
cd Documents

# Aller dans le dossier Documents (absolu)
cd /home/alice/Documents

# Remonter d'un niveau dans l'arborescence
cd ..

# Remonter de deux niveaux dans l'arborescence
cd ../..

# Aller dans le dossier personnel de l'utilisateur·trice
cd ~

# Revenir au répertoire précédent
cd -
```

## Autocomplétion avec Tab

La touche `Tab` est votre meilleure allie au terminal. Elle complète
automatiquement les noms de fichiers, dossiers et commandes.

```bash title="Terminal Bash/Zsh"
cd Doc<Tab>  # Complete en cd Documents/ si le dossier existe
```

Si plusieurs correspondances existent, appuyez deux fois sur `Tab` pour les
afficher toutes.

Vous pourrez ensuite continuer à taper le nom du fichier ou dossier pour affiner
la recherche, puis appuyer à nouveau sur `Tab` pour compléter.

Apprenez à utiliser l'autocomplétion dès le début, cela vous fera gagner
beaucoup de temps et réduira les erreurs de frappe.

## Historique des commandes

Le terminal conserve un historique des commandes saisies :

- **Flèche haut / bas** : naviguer dans l'historique.
- `Ctrl+R` : recherche dans l'historique (saisissez un mot-clé pour trouver une
  commande précédente).
- `history` : affiche toutes les commandes de l'historique.

## Résumé

Les commandes `pwd`, `ls` et `cd` constituent le trio fondamental de la
navigation en terminal. Maîtriser les chemins absolus et relatifs, ainsi que
l'autocomplétion par `Tab`, rend le travail en ligne de commande fluide et
rapide.

### Exercice pratique - Naviguer dans l'arborescence de fichiers

Soit l'arborescence de fichiers suivante :

```text
/home/alice/
├── Documents/
│   ├── Projet1/
│   └── Projet2/
├── Images/
└── Musique/
```

Répondez aux questions suivantes en utilisant les commandes `pwd`, `ls` et `cd`
:

- Si vous êtes dans `/home/alice`, comment accéder au dossier `Projet1` ?
- Si vous êtes dans `/home/alice/Documents/Projet1`, comment revenir au dossier
  `Documents` ?
- Si vous êtes dans `/home/alice/Documents/Projet1`, comment accéder au dossier
  `Images` ?

<details>
<summary>Afficher les réponses</summary>

- `cd Documents/Projet1` ou `cd /home/alice/Documents/Projet1`
- `cd ..` ou `cd /home/alice/Documents`
- `cd ../../Images` ou `cd /home/alice/Images`

</details>

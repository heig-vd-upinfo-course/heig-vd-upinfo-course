Dans ce dernier contenu, nous allons apprendre à écrire un script simple en Bash
et à l'exécuter.

Un script est un fichier texte contenant une séquence de commandes que le shell
exécute automatiquement de lignes en lignes à l'aide d'un interpréteur (voir
contenus
[Applications](/heig-vd-upinfo-course/03-composants-materiels-et-logiciels-dun-ordinateur/12-applications/)).

Un script permet d'automatiser des tâches répétitives et d'enchaîner des
opérations complexes en une seule commande. Nous allons voir comment créer un
script Bash, le rendre exécutable et l'exécuter.

## Créer un script Bash

Un script Bash est un fichier texte avec l'extension `.sh`. Voici un exemple
minimal d'un script Bash nommé `mon-script.sh` qui affiche le texte "Hello,
world !" à l'écran :

```bash title="mon-script.sh"
#!/usr/bin/env bash
echo "Hello, world !"
```

La première ligne (`#!/usr/bin/env bash`) s'appelle le **shebang**. Elle indique
au système quel interpréteur utiliser pour exécuter le script. Sans elle, le
système ne sait pas quel shell utiliser pour exécuter le script (voir le contenu
[Terminal et shells](/heig-vd-upinfo-course/05-configurer-son-systeme-dexploitation-et-ses-applications/04-terminal-et-shells/)).

Dans cet exemple, le shell Bash est utilisé pour exécuter le script. La deuxième
ligne utilise la commande `echo` pour afficher le texte "Hello, world !" à
l'écran.

## Rendre un script exécutable

Par défaut, un fichier texte n'est pas exécutable. Il faut lui accorder la
permission d'exécution (voir le contenu
[Utilisateur·trices, groupes et permissions](/heig-vd-upinfo-course/03-composants-materiels-et-logiciels-dun-ordinateur/13-utilisateur-trices-groupes-et-permissions/))
avant de pouvoir l'exécuter. Pour cela, utilisez la commande `chmod` (qui
signifie "change mode") :

```bash title="Terminal Bash/Zsh"
chmod +x mon-script.sh
```

L'option `+x` ajoute la permission d'exécution sur le fichier `mon-script.sh`.

Sans cette permission, si vous essayez d'exécuter le script, vous obtiendrez une
erreur du type "Permission denied".

## Exécuter un script

Une fois le script rendu exécutable, vous pouvez l'exécuter de la manière
suivante :

```bash title="Terminal Bash/Zsh"
# Exécuter le script qui est présent dans le répertoire courant
./mon-script.sh
```

## Variables

Afin de rendre nos scripts plus dynamiques, nous pouvons utiliser des variables.
Une variable est un espace de stockage qui peut contenir une valeur, comme un
texte ou un nombre.

Voici un exemple de script qui utilise une variable pour stocker un nom et
l'afficher :

```bash title="mon-script.sh"
#!/bin/bash
NOM="Alice"

echo "Bonjour, $NOM !"
```

Ici, la variable `NOM` contient la valeur "Alice".

Pour utiliser la variable dans le script, on utilise le signe `$` devant le nom
de la variable. Ainsi, `echo "Bonjour, $NOM !"` affichera "Bonjour, Alice !".

## Variables d'environnement

Les variables d'environnement sont des variables prédéfinies par le système ou
définies par l'utilisateur·trice qui influencent le comportement des processus
et des applications.

Elles sont accessibles dans les scripts et peuvent être utilisées pour stocker
des informations importantes, comme le chemin d'accès aux fichiers ou les
paramètres de configuration.

La variable d'environnement `HOME` contient le chemin du répertoire personnel de
l'utilisateur·trice. Par exemple, pour afficher le chemin du répertoire
personnel, vous pouvez utiliser la commande suivante dans un script :

```bash title="mon-script.sh"
#!/usr/bin/env bash
echo "Votre répertoire personnel est : $HOME"
```

```text
# Votre répertoire personnel est : /home/votre-nom-utilisateur
```

Une autre variable d'environnement est `USER`, qui contient le nom de
l'utilisateur·trice actuellement connecté·e. Vous pouvez l'utiliser dans un
script pour afficher le nom de l'utilisateur·trice :

```bash title="mon-script.sh"
#!/usr/bin/env bash
echo "Vous êtes connecté·e en tant que : $USER"
```

```text
# Vous êtes connecté·e en tant que : votre-nom-utilisateur
```

## Résumé

Écrire des scripts est une compétence clé pour automatiser des tâches
répétitives. Un script Bash commence par un shebang, s'exécute après un
`chmod +x`, et peut utiliser des variables, des arguments et d'autres structures
que vous étudierez en cours.

### Exercice pratique - Valider votre configuration à l'aide d'un script

Dans ce dernier contenu pratique, vous allez créer un script Shell qui affiche
un résumé des informations de votre système, y compris le nom d'utilisateur, le
répertoire personnel, le type et la version du système d'exploitation,
l'architecture et le modèle du processeur, l'utilisation de la mémoire et du
stockage, le shell actuel et les outils installés (SSH, Git, Docker et Docker
Compose) avec leurs versions respectives.

Cela vous permettra de vérifier que votre configuration est correcte et que tous
les outils de base sont installés et fonctionnent correctement.

Avec tout ce que vous avez acquis jusqu'ici, vous devriez être capable de créer
ce script localement et de l'exécuter pour vérifier votre configuration.

La marche à suivre est décrite ci-dessous, mais essayez d'abord de le faire par
vous-même. Si vous avez des difficultés, vous pouvez suivre les instructions pas
à pas.

Validez votre configuration en exécutant le script `sysinfo.sh` et en vérifiant
que toutes les informations affichées sont correctes et que tous les outils de
base sont installés et fonctionnent correctement.

<Steps>

1. Créez un fichier nommé `sysinfo.sh` dans votre répertoire personnel ou dans

3. Enregistrez le fichier et fermez l'éditeur.

4. Ouvrez un terminal et naviguez jusqu'au répertoire où se trouve le fichier

   ```bash title="Terminal Bash/Zsh"
   cd ~
   ```

   ```bash title="Terminal Bash/Zsh"
   chmod +x sysinfo.sh
   ```

6. Exécutez le script en utilisant la commande suivante :

   ```bash title="Terminal Bash/Zsh"
   ./sysinfo.sh
   ```

7. Le script affichera un résumé des informations de votre système, y compris le

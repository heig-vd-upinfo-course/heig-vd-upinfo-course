# Avertissement IA

Des outils d'intelligence artificielle ont été utilisés pour assister le
développement de ce dépôt. Les sections suivantes présentent les outils d'IA
utilisés, les processus concernés, le niveau d'assistance IA apporté à chaque
processus, ainsi que les inspirations et références utilisées pour créer cet
avertissement.

## Processus

Les processus suivants ont été utilisés dans le développement de ce dépôt, avec
le niveau d'assistance IA indiqué pour chaque processus :

- **Conception** : aucune
- **Implémentation** : assistée avec IA
- **Tests** : suggestions d'IA
- **Documentation** : suggestions d'IA
- **Revue** : aucune
- **Déploiement** : aucune

### Conception

La conception de ce dépôt a été réalisée par une personne développeuse sans
utiliser d'outils d'IA.

Le processus de conception a consisté à planifier la structure, l'organisation
et le contenu du dépôt afin de répondre aux exigences du projet et de respecter
les bonnes pratiques.

### Implémentation

[GitHub Copilot](https://github.com/features/copilot) et
[Claude Code](https://www.anthropic.com/product/claude-code) ont été utilisés
pour assister l'implémentation de ce dépôt.

La structure et l'organisation du dépôt ont été conçues par une personne
développeuse, avec les pages principales et un contenu initial.

Une première version a été produite en demandant à GitHub Copilot de générer le
contenu de chaque page a partir des titres et des indications du contenu
initial.

Une revue approfondie du contenu généré a été effectuée par une personne
développeuse afin de vérifier qu'il répondait aux exigences du projet, en
modifiant, ajoutant et supprimant du contenu lorsque nécessaire. La personne
développeuse a également vérifié que le contenu était exact et pertinent pour le
projet.

Les outils d'IA ont parfois suggéré des améliorations ou des approches
alternatives, qui ont été revues et adaptées par une personne développeuse avant
d'être ajoutées au dépôt.

Une fois le contenu principal terminé, Claude Code a été utilisé pour générer
les diapositives de présentation Marp à partir du contenu du dépôt. Les
diapositives générées ont été revues et modifiées par une personne développeuse
avant d'être ajoutées au dépôt.

### Tests

Les tests de ce dépôt ont été réalisés par une personne développeuse sans
utiliser d'outils d'IA.

Le processus de test a consisté à vérifier que le contenu était exact, pertinent
et conforme aux exigences du projet. La personne développeuse a aussi vérifié
que le contenu était exempt d'erreurs et d'incohérences.

### Documentation

La documentation de ce dépôt a été rédigée par une personne développeuse avec
une aide partielle d'outils d'IA.

Le processus de documentation a consisté à produire une documentation claire et
concise expliquant comment utiliser le dépôt et ce qu'il contient.

Les outils d'IA ont été utilisés pour proposer des améliorations ou des
approches alternatives, qui ont été revues et adaptées par une personne
développeuse avant d'être ajoutées à la documentation.

### Revue

La revue de ce dépôt a été effectuée par une personne développeuse sans utiliser
d'outils d'IA.

Le processus de revue est le suivant :

- Une issue est créée sur GitHub pour décrire la tâche à réaliser.
- Une branche est créée pour cette tâche.
- La tâche est réalisée, parfois avec des outils d'IA comme décrit ci-dessus.
- Une pull request est créée pour la branche, puis une personne développeuse
  relit le code pour vérifier qu'il respecte les exigences de la tâche et les
  bonnes pratiques.
- La pull request est approuvée et fusionnée dans la branche principale.
- L'issue est fermée.

### Déploiement

Le déploiement de ce dépôt a été effectué par une personne développeuse sans
utiliser d'outils d'IA.

Le processus de déploiement a été automatisé avec un workflow
[GitHub Actions](https://github.com/features/actions) qui construit et déploie
le dépôt vers [GitHub Pages](https://pages.github.com/) à chaque push sur la
branche principale. La personne développeuse a vérifié le bon déroulement du
déploiement et l'accessibilité du dépôt pour les personnes utilisatrices.
